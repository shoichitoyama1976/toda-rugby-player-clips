# 戸田ラグビー選手記事帖

非公式の選手記事一覧です。ヤクルトレビンズ戸田、株式会社ヤクルト本社、ジャパンラグビーリーグワンの公式サイトではありません。

公開サイト: https://toda-rugby-player-clips.grok.me

副題: Lovins Clips Connect With Levins

レビンズの選手が出てきたオンライン記事を、選手や媒体ごとにたどります。本文は転載せず、元の記事へ案内します。名前だけの告知は入れていません。

## できること

- ホームと選手ページは、同じ人数・同じ順です。現役の FW、BK、スタッフ・関係者のあと、過去所属が同じ順で続きます。FW と BK はプロップからフルバックの順です
- 記事は、公式HP、公式note、リーグワン、その他の4つに分けます。媒体名の先頭には、X や note などの印を付けます
- 試合のメンバー表から、その人の記事一覧へ進みます。漢字の名前にはふりがな、カタカナの名前にはアルファベットを添えます
- ヘッダーの「屋外」で、日差しの下でも読める明るい表示に切り替えます。選んだ表示は、そのブラウザに残ります
- メニューは、ホーム、試合、選手、記事、保存した記事、このサイトについて、修正依頼
- 年齢と在籍年数は、生年月日と加入年からその場で計算します。シートには置きません
- 選手ページには、X、Instagram、note、公式プロフィールへのリンクを、判別できる印で出します
- 修正依頼の最初の選択肢は「掲載削除」です。選手やクラブから外せと連絡があれば外します
- 修正依頼を受けたとき、公開先に `GITHUB_TOKEN` があれば GitHub の Issue を作り、担当者を付けます

## 正本

選手名簿、掲載記事、試合、出場メンバーは **Google スプレッドシート** です。このリポジトリには、その行データは入れていません。

読むシートは、Players、Clips、Matches、Lineups です。サイトは最大5分キャッシュします。すぐ反映するときは、プレビューの「いま読み直す」です。

上の帯に出る記事数・名簿数は、シートの行数です。サイト本体の件数は、アドレスの無い行を除き、同じアドレスを1件にまとめたあとの数です。両方が違っていても、読み込みの失敗ではありません。

Matches と Lineups が空のときだけ、`src/data/lineups.ts` の見本を出します。

## プレビューだけで見えるもの

公開サイトを普通に開いた人には出しません。

- 質問、プレビューを更新、公開サイトを更新。選んでいる一つが白く塗られます。公開そのものは、Grok の公開を押したときに行われます
- シートを最後に読んだ時刻、行数、次の自動読み込みまでの目安
- 公式Xのメンバー確認。毎日同じ時刻に動き、作業は木曜と金曜だけです。予約は7日で切れ、切れる前日から「続ける」が出ます
- 「コミット」。その時点のサイトの作りを、このリポジトリに残します

## このリポジトリに無いもの

- 選手名簿、掲載記事、試合、出場メンバーの行データ
- 運営者ページの合い言葉（サーバーの環境変数 `TODA_REVIEW_PIN` のみ）
- Issue を作るための GitHub の鍵（サーバーの環境変数 `GITHUB_TOKEN` のみ）
