# 戸田ラグビー選手記事帖

非公式の選手記事一覧です。ヤクルトレビンズ戸田、株式会社ヤクルト本社、ジャパンラグビーリーグワンの公式サイトではありません。

公開サイト: https://toda-rugby-player-clips.grok.me

レビンズの選手が出てきたオンライン記事を、選手や媒体ごとにたどります。本文は転載せず、元の記事へ案内します。

## できること

- 選手、記事、媒体から、元の記事へ案内する
- 試合のメンバー表から、その選手の記事一覧へ進む
- 記事は、公式HP、公式note、リーグワン、その他に分ける
- ヘッダーの「屋外」で、日差しの下でも読める明るい表示に切り替える。選んだ表示は、そのブラウザに残る
- 選手一覧は、現役の FW、BK、スタッフ・関係者の順。そのあとに過去所属を、同じ順で続ける。FW と BK はプロップからフルバックの順
- メニューは、ホーム、試合、選手、記事、保存した記事、このサイトについて、修正依頼
- 修正依頼を受けたとき、公開先に `GITHUB_TOKEN` があれば GitHub の Issue を作り、担当者を付ける

## 正本

選手名簿と掲載記事は **Google スプレッドシート** です。このリポジトリには記事の中身も選手の実データも入れていません。

試合のメンバー表は、スプレッドシートの Matches と Lineups を読む。シートが空のときだけ、`src/data/lineups.ts` の見本を出す。

サイトマップに書く公開アドレスは `https://toda-rugby-player-clips.grok.me` です。

## このリポジトリに無いもの

- 選手名簿・掲載記事の行データ
- 運営者ページの合い言葉（サーバーの環境変数 `TODA_REVIEW_PIN` のみ）
- Issue を作るための GitHub の鍵（サーバーの環境変数 `GITHUB_TOKEN` のみ）
