# 戸田ラグビー選手記事帖

非公式の選手記事一覧です。ヤクルトレビンズ戸田、株式会社ヤクルト本社、ジャパンラグビーリーグワンの公式サイトではありません。

公開サイト: https://toda-rugby-player-clips.app

副題: Lovins Clips Connect With Levins

レビンズの選手が出てきたオンライン記事を、選手や媒体ごとにたどります。本文は転載せず、元の記事へ案内します。名前だけの告知は入れていません。加入前の記事や、退団後の記事も残しています。

## 三つの役割

画面とプログラムは、この三つで分けています。

1. **Grok** で直し、プレビューで確認します。
2. **GitHub** のこのリポジトリに残します。`main` が正です。
3. **Cloudflare** が `main` をビルドして、公開サイトを更新します。

Grok の `grok.me` は、作っている途中を見るためのものです。公開先には使いません。

## できること

- ホームと選手ページは、同じ人数・同じ順です。現役の FW、BK、スタッフ・関係者のあと、過去所属が同じ順で続きます。FW と BK はプロップからフルバックの順です
- ホームの試合カードは、今日から6日以内の試合だけ出します。それより前の結果は、試合ページに残します
- その週に試合がないときは、カードの代わりに文章を出します。6日以内のイベントがあれば「公式Xでイベント情報が出ています。」に続けて、シートの概要を出します。イベントもなく、最後の試合から3週間以内か、その先に試合があれば「今週は試合がありません。」です。それより空けば「オフシーズンです。」
- 終了した試合の得点は、レビンズのエンブレム、チーム名、得点、相手の得点、チーム名、エンブレムの順です。名前は Teams の「チーム名」です。短縮名は使いません。得点の数字はスチールブルーです
- 会場のうしろに（ホーム）（ビジター）（中立）を出します。空欄のときは出しません
- ホームの試合カード、試合一覧、試合ページは、同じ見出しです。種別、対戦カード、得点、日付、キックオフ、会場です
- リーグワン公式の試合レポートURLがあるときだけ、「リーグワン公式の試合レポートを開く」を出します。公式戦以外は空欄のままです
- 選手ページは、上から順に絞ります。全員・FW・BK・スタッフ、その次にポジション、その次に入団年です。上を選び直すと、下の選択は外れます
- 記事は、公式HP、公式note、リーグワン、その他の4つに分けます。媒体名の先頭には、X や note などの印を付けます。昔の媒体名で開いたアドレスは、この4つのどれかへ移します
- 試合のメンバー表から、その人の記事一覧へ進みます。名前と読みは選手名簿のものを出します。番号の右にポジションを出します
- 試合ページから、レビンズと対戦相手の公式Xのメンバー投稿を開けます
- ヘッダーの「屋外」で、日差しの下でも読める明るい表示に切り替えます。選んだ表示は、そのブラウザに残ります
- メニューは、ホーム、試合、選手、記事、リンク、保存した記事、このサイトについて、修正依頼です
- 年齢と在籍年数は、生年月日と加入年からその場で計算します。シートには置きません
- 選手ページには、X、Instagram、note、公式プロフィールへのリンクを、判別できる印で出します
- 書体は端末のものを使います。Aptos が入っているパソコンでは Aptos が先です。文字ファイルは配信しません
- アクセス計測のタグは入れていません
- 修正依頼の最初の選択肢は「掲載削除」です。選手やクラブから外せと連絡があれば外します
- 修正依頼を受けたとき、公開先に `GITHUB_TOKEN` があれば GitHub の Issue を作り、担当者を付けます

## データ

表示に使う行は、このリポジトリの CSV です。ページを開くたびに Google スプレッドシートは読みません。

| ファイル | 内容 |
| --- | --- |
| `src/data/players.csv` | 選手、スタッフ、ホームタウン |
| `src/data/clips.csv` | 掲載記事 |
| `src/data/matches.csv` | 試合。終了した試合は「レビンズ得点」「相手得点」に数字だけを入れる。開催は「ホームビジター」にホーム、ビジター、中立。リーグワン公式戦の試合レポートURLがあるときだけ、カードにリンクを出す |
| `src/data/teams.csv` | チーム名。得点の横には「チーム名」と、Logo 列のエンブレムを出す |
| `src/data/events.csv` | 試合のない週の案内。ホームの文章に使います。メニューには出しません |
| `src/data/lineups.csv` | 出場メンバー |
| `src/data/links.csv` | リンク集。グループの値ごとに分けて出します。その他はサイト名だけです |

スプレッドシートは、記事やメンバーを書き溜める作業用です。直したあとは、同じ内容を上の CSV に写してこのリポジトリへ残します。Cloudflare が `main` をビルドすると、公開サイトに載ります。

`lineups.csv` に行がないときだけ、`src/data/lineups.ts` の見本を出します。

## 記事の探し方

現役の選手だけを、新しく探します。引退した選手は、これから集めません。名前だけの加入告知は入れません。本人の声や、その人の輪郭が残っているものだけです。

レビンズ在籍中だけでなく、加入前も探します。大学、高校、ラグビースクール、経歴にある過去の所属チームです。その記事に「レビンズ」という語が無くても対象です。

ラグビーリパブリック（`rugby-rp.com`）と日刊スポーツ（`nikkansports.com`）は、毎回そのサイトの中で名前を引きます。日付で直近に限りません。加入前のインタビューが、ここに残っているためです。

名前は、名簿の漢字と、よくあるゆれの両方で探します。髙田と高田、﨑と崎、斉と齊と斎、島と嶌、です。

すでに載っているか比べるときは、URLから `fbclid` や `utm_` を外します。Facebookなどから開いたアドレスは、記事の本体と別の文字が付きます。

## 公開

公開サイトは Cloudflare です。`grok.me` は、ホスト側が検索結果に出さない指定を付けるので、公開先には使いません。

記事の個別ページだけ `noindex` です。本文を載せず、元の記事へ案内するためです。原文の代わりに検索へ出す流れにはしません。選手ページと試合の一覧は、このサイトの入口なので検索に出します。原文が 404 または 410 のときは「この原文はリンク切れです。」と出します。到達できないだけのサイトは、リンク切れにしません。`robots.txt` で外しているのは `/inbox` と `/saved` です。

## プレビューだけで見えるもの

公開サイトを普通に開いた人には出しません。

- 質問、プレビューを更新、公開サイトを更新。選んでいる一つが白く塗られます
- シートを最後に読んだ時刻と、行数
- 公式Xのメンバー確認。予約は7日で切れ、切れる前日から「続ける」が出ます
- 「コミット」。その時点のサイトの作りを、このリポジトリに残します

## このリポジトリに無いもの

- 運営者ページの合い言葉（サーバーの環境変数 `TODA_REVIEW_PIN` のみ）
- Issue を作るための GitHub の鍵（サーバーの環境変数 `GITHUB_TOKEN` のみ）
